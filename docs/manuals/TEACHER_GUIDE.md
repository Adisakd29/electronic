# คู่มือครู

รายวิชา งานไฟฟ้าและอิเล็กทรอนิกส์เบื้องต้น (20100-1005) · 18 สัปดาห์ × 4 ชั่วโมง (ทฤษฎี 1 + ปฏิบัติ 3)

## 1. ภาพรวมการจัดการเรียนรู้บนเว็บไซต์

แต่ละสัปดาห์มีเส้นทางการเรียน 6 ขั้น นักเรียนเรียนตามลำดับได้ทั้งในห้องและนอกเวลา ระบบบันทึกความก้าวหน้าเองทุกขั้น

| ขั้น | นักเรียนทำอะไร | ระบบนับว่าเสร็จเมื่อ |
|---|---|---|
| 1. บทนำ | อ่านจุดประสงค์ (ความรู้/ทักษะ/คุณลักษณะ) สถานการณ์จริง คำถามอุ่นเครื่อง แบบทดสอบก่อนเรียน 5 ข้อ (ทำได้ครั้งเดียว ข้ามได้) | กด “เริ่มเรียน” |
| 2. เรียนรู้ | เนื้อหาแบ่งเป็นขั้น (Step) ทีละหน้า มีภาพ สูตร ตัวอย่างพร้อมเฉลย และคำถามระหว่างเรียน | ทำทุก Step เสร็จ |
| 3. ฝึกปฏิบัติ | กิจกรรมโต้ตอบ (จับคู่ เรียงลำดับ เติมค่า ทำนายผล หาจุดผิด จัดกลุ่ม สถานการณ์) ตอบผิดได้และเห็นเหตุผลที่ผิด | ตอบถูกครบทุกข้ออย่างน้อยครั้งละหนึ่ง |
| 4. ห้องทดลองเสมือน | ภารกิจในแบบจำลองแรงดันต่ำ ระบบตรวจผลจากสถานะของแบบจำลอง และใบงานปฏิบัติจริงสำหรับโรงฝึกงาน | ภารกิจห้องทดลองครบ |
| 5. แบบทดสอบ | สุ่มข้อสอบจากคลัง (ไม่ซ้ำชุดเดิม) ทำซ้ำได้ ระบบเก็บคะแนนสูงสุด | ผ่านเกณฑ์ (ค่าเริ่มต้น 60 %) |
| 6. สรุปและจบบท | สรุปประเด็น แผนผังความคิด สูตร คำศัพท์ แหล่งเรียนรู้ ภารกิจท้าทายประจำสัปดาห์ | ขั้น 1–5 เสร็จแล้วกด “จบบทเรียนสัปดาห์นี้” |

**การใช้ในคาบเรียน 4 ชั่วโมง (แนะนำ):** ชั่วโมงที่ 1 ครูนำด้วยบทนำและขั้นเรียนรู้บนจอ (เปิดในโหมดดูตัวอย่างของครู) ชั่วโมงที่ 2–4 นักเรียนทำขั้นฝึกปฏิบัติและห้องทดลองเสมือนเป็นคู่ แล้วทำใบงานปฏิบัติจริงที่โต๊ะปฏิบัติ แบบทดสอบให้ทำท้ายคาบหรือเป็นการบ้าน

**ระดับความปลอดภัยของใบงาน** (แสดงเป็นป้ายบนใบงานทุกชุด ตรวจก่อนแจกทุกครั้ง)

| ระดับ | ความหมาย |
|---|---|
| S0 นักเรียนทำได้เอง | ไม่มีแหล่งจ่าย หรือแรงดันไม่เกิน 12 V DC แบบจำกัดกระแส |
| S1 ครูตรวจก่อนจ่ายไฟ | นักเรียนทำเอง แรงดันไม่เกิน 24 V ครูตรวจวงจรก่อนจ่ายไฟทุกครั้ง |
| S2 ครูควบคุมใกล้ชิด | งานที่มีความร้อน (เช่น บัดกรี) สารเคมี หรือเครื่องใช้ไฟฟ้าแรงดันสูงแบบปิดมิดชิด |
| S3 ครูสาธิตเท่านั้น | มีจุดไฟฟ้า 230/400 V เปิดโล่ง นักเรียนสังเกตการณ์ ห้ามลงมือเอง |

**ผู้เยี่ยมชม:** คนที่ไม่ได้เข้าสู่ระบบเรียนได้ทุกสัปดาห์ (ไม่ติดล็อก) แต่ผลเก็บในเบราว์เซอร์ของเขาเท่านั้น ครูไม่เห็นข้อมูลนี้ ไม่มีแบบทดสอบ (คลังข้อสอบและเฉลยจึงไม่หลุดออกไป) และส่งใบงานไม่ได้ ควรย้ำให้นักเรียนในชั้นเข้าสู่ระบบก่อนเรียน ผู้ดูแลระบบปิดโหมดนี้ได้ด้วยตัวแปร `GUEST_MODE=off`

## 1.1 นักเรียนต่างแผนก

วิชานี้เป็นวิชาพื้นฐานที่ช่างหลายสาขาเรียน บทเรียนจึงมีตัวช่วย 3 แบบสำหรับนักเรียนที่ไม่ได้มาจากแผนกอิเล็กทรอนิกส์ โดยเนื้อหาที่ประเมิน ข้อสอบ และเกณฑ์ผ่านเหมือนกันทุกแผนก

- **เข้าใจแบบง่าย ๆ ก่อน** (กรอบสีเขียว) ต้นขั้นเรียนรู้แทบทุกขั้น อธิบายด้วยภาษาธรรมดาและการเปรียบเทียบก่อนเข้าสู่ศัพท์และสูตร
- **ลงลึก (อ่านเพิ่ม · ไม่ออกสอบ)** พับเก็บรายละเอียดที่ไม่ได้ใช้ในการประเมิน นักเรียนที่สนใจกดเปิดอ่านได้
- **ในงานแผนกของคุณ** ตัวอย่างจากงานจริงของ 6 แผนก: ช่างยนต์, ช่างกล/เชื่อม/ซ่อมบำรุง, ช่างก่อสร้าง/โยธา, ช่างไฟฟ้ากำลัง, ช่างเครื่องทำความเย็นและปรับอากาศ, ช่างเทคนิคคอมพิวเตอร์ ทุกสัปดาห์มีที่บทนำและอีก 3 จุดในขั้นเรียนรู้

**ตั้งแผนกของห้อง** ที่เมนู **บัญชีนักเรียน → แผนกของห้องนี้** นักเรียนทุกคนในห้องจะเห็นตัวอย่างของแผนกนั้น นักเรียนเปลี่ยนเป็นแผนกของตัวเองได้ที่แดชบอร์ดหรือด้านบนของบทเรียน (เลือก "ตามห้องเรียน" เพื่อกลับไปใช้แผนกของห้อง) ระบบจำค่าไว้ในบัญชี เปลี่ยนเครื่องก็ยังเหมือนเดิม

## 2. เริ่มต้นภาคเรียน

1. ผู้ดูแลระบบสร้างห้องเรียน (เช่น “ชฟ.1/1” ภาคเรียน “2/2569”) และกำหนดครูผู้สอนที่เมนู **ผู้ดูแลระบบ → ห้องเรียน**
2. ครูสร้างบัญชีนักเรียนที่ **บัญชีนักเรียน → สร้างบัญชีนักเรียนหลายคนพร้อมกัน** วางรายชื่อบรรทัดละคนในรูปแบบ
   ```
   username,ชื่อ-นามสกุล,เลขประจำตัว
   s6601,สมชาย ใจดี,6601
   ```
   ระบบแสดงรหัสผ่านชั่วคราว **เพียงครั้งเดียว** ให้ดาวน์โหลด CSV เก็บไว้แจกนักเรียน นักเรียนต้องเปลี่ยนรหัสผ่านเมื่อเข้าสู่ระบบครั้งแรก
3. (ถ้าเปิดใช้ Google) เพิ่มอีเมล Google ของนักเรียนที่ **บัญชีนักเรียน → อีเมล Google ที่อนุญาต** เมื่อนักเรียนเข้าสู่ระบบด้วย Google ครั้งแรก ระบบจะเพิ่มเข้าห้องให้อัตโนมัติ
4. ตั้งเกณฑ์ปลดล็อกที่ **การปลดล็อก** (หัวข้อ 4)

## 3. ติดตามผู้เรียน

| เมนู | ใช้ทำอะไร |
|---|---|
| **ภาพรวม** | จำนวนนักเรียนที่เริ่มเรียนและเรียนจบแต่ละสัปดาห์ ค่าเฉลี่ยห้อง และ “นักเรียนที่ควรติดตาม” (ไม่ได้เข้าเรียน 7 วัน, สอบไม่ผ่าน 2 ครั้ง, ใบงานเลยกำหนด) |
| **นักเรียน** | ตารางสัปดาห์ปัจจุบัน ความก้าวหน้า % คะแนนเฉลี่ย และวันที่ใช้งานล่าสุด กดชื่อเพื่อดูรายละเอียดทุกสัปดาห์ ผลแบบทดสอบ ผลห้องทดลอง กิจกรรมที่ตอบผิด ใบงาน และสมรรถนะ |
| **คำถามที่ตอบผิดบ่อย** | วิเคราะห์ข้อสอบรายข้อ (% ตอบถูก ตัวเลือกผิดที่ถูกเลือกบ่อยที่สุด) และกิจกรรมในบทเรียนที่ตอบผิดบ่อย ใช้วางแผนสอนซ่อมเสริมในคาบถัดไป |
| **ก่อน–หลังเรียน** | ค่าเฉลี่ยคะแนนก่อนเรียนเทียบหลังเรียนรายสัปดาห์ และพัฒนาการรายคน |
| **ห้องทดลอง** | อัตราการทำภารกิจห้องทดลองสำเร็จรายภารกิจ และสถานะรายบุคคล |
| **ใบงาน** | ใบงานที่ส่ง/ยังไม่ส่ง กรองตามสัปดาห์และสถานะ |

ในหน้ารายละเอียดนักเรียน ครูทำได้: ปลดล็อกสัปดาห์ให้นักเรียนคนนั้น, รีเซ็ตรหัสผ่าน (ได้รหัสชั่วคราวแสดงครั้งเดียว), ออกเกียรติบัตร

## 4. ระบบปลดล็อกบทเรียน

ค่าเริ่มต้น: สัปดาห์ที่ 1 เปิดเสมอ สัปดาห์ถัดไปเปิดเมื่อสัปดาห์ก่อนหน้า **เรียนรู้ครบ + ฝึกปฏิบัติครบ + ห้องทดลองครบ + แบบทดสอบได้อย่างน้อย 60 %** (การส่งใบงานยังไม่บังคับ)

ที่เมนู **การปลดล็อก** ครูทำได้:
- **เปิด/ปิดระบบล็อก** ทั้งห้อง (ปิดล็อก = นักเรียนเปิดได้ทุกสัปดาห์)
- **เกณฑ์การปลดล็อก**: เลือกว่าต้องผ่านขั้นใด กำหนดคะแนนขั้นต่ำ และเลือกบังคับส่งใบงาน ตั้งเป็นค่าเริ่มต้นของห้องหรือเฉพาะบางสัปดาห์ได้
- **เปิดสัปดาห์ให้ทั้งห้อง** เช่น เมื่อสอนเร็วกว่าแผน
- **ปลดล็อกรายบุคคล** เช่น นักเรียนที่ขาดเรียนเพราะป่วยแต่ได้ทำงานชดเชยกับครูแล้ว

- **ต้องเรียนตามลำดับขั้นในสัปดาห์** (เปิดอยู่เป็นค่าเริ่มต้น): นักเรียนต้องทำ บทนำ → เรียนรู้ → ฝึกปฏิบัติ → ห้องทดลอง → แบบทดสอบ → สรุป ตามลำดับ ขั้นถัดไปจะเปิดเมื่อขั้นก่อนหน้าเสร็จ ขั้นที่เสร็จแล้วกลับมาทบทวนได้ตลอด และสัปดาห์ที่จบแล้วเปิดทุกขั้น ระบบตรวจลำดับนี้ที่เซิร์ฟเวอร์ (ไม่ใช่แค่ซ่อนปุ่ม) ถ้าต้องการให้นักเรียนเปิดทุกขั้นได้อิสระ ให้ติ๊กช่องนี้ออกในเกณฑ์ของห้องหรือเฉพาะบางสัปดาห์

เมื่อสัปดาห์ยังล็อก นักเรียนจะเห็นข้อความบอกว่ายังขาดอะไร (เช่น “ผ่านแบบทดสอบสัปดาห์ที่ 3 อย่างน้อย 60 %”) และเมื่อขั้นยังไม่เปิด จะเห็นว่าต้องทำขั้นใดก่อนพร้อมปุ่มไปยังขั้นนั้น

## 5. ตรวจใบงาน

1. **ใบงาน** → เลือกงานที่ส่ง → เปิดไฟล์ (PDF แสดงในหน้า, รูปภาพแสดงในหน้า, DOCX ดาวน์โหลด)
2. ให้ระดับ 1–4 ในแต่ละเกณฑ์ของรูบริก ระบบคำนวณคะแนนตามน้ำหนักให้
3. เขียนข้อเสนอแนะ แล้วเลือก **ให้คะแนน** หรือ **ส่งกลับแก้ไข** (การส่งกลับต้องมีข้อเสนอแนะ)
4. นักเรียนเห็นคะแนนและข้อเสนอแนะที่แดชบอร์ดและหน้าใบงาน ส่งไฟล์ใหม่แทนไฟล์เดิมได้

ใบงานทุกชุดพิมพ์ได้ (ปุ่ม “พิมพ์ใบงาน” ขนาด A4) มีช่องชื่อ เลขที่ ห้อง วันที่ ตารางบันทึกผล คำถาม และรูบริก ครูจะเห็น “ผลที่คาดหวัง” ของใบงานในหน้าใบงานด้วย นักเรียนไม่เห็นส่วนนี้

## 6. ประเมินสมรรถนะ

เมนู **ประเมินสมรรถนะ** เป็นตารางนักเรียน × สมรรถนะรายวิชา 4 ข้อ และการประเมินปลายภาค (สัปดาห์ที่ 18)

| รหัส | สมรรถนะรายวิชา |
|---|---|
| 1 | แสดงความรู้เกี่ยวกับหลักการวัด ทดสอบ ประกอบวงจรไฟฟ้าและอิเล็กทรอนิกส์เบื้องต้นและความปลอดภัย |
| 2 | ประกอบและตรวจสอบวงจรไฟฟ้าเบื้องต้น |
| 3 | ต่อวงจรและตรวจสอบอุปกรณ์อิเล็กทรอนิกส์เบื้องต้น |
| 4 | ใช้เครื่องมือวัดทดสอบวงจรไฟฟ้าและวงจรอิเล็กทรอนิกส์ |

บันทึกระดับ 1–4 คะแนน ผ่าน/ไม่ผ่าน และหมายเหตุ เกณฑ์การประเมินปลายภาคและรูบริกอยู่ในสัปดาห์ที่ 18 (เปิดดูในโหมดครู) **เกียรติบัตร** ออกให้อัตโนมัติเมื่อนักเรียนเรียนจบครบ 18 สัปดาห์และผ่านการประเมินปลายภาค หรือครูออกเองจากหน้ารายละเอียดนักเรียน ทุกใบมีรหัสตรวจสอบที่ `/certificate/verify`

## 7. คลังข้อสอบ

แต่ละสัปดาห์มีข้อสอบ 30–32 ข้อ ระบุระดับ Bloom (จำ/เข้าใจ/ประยุกต์/วิเคราะห์) แบบทดสอบหลังเรียนสุ่มตามสัดส่วนระดับที่กำหนด ที่เมนู **คลังข้อสอบ** ครูทำได้:
- ค้นหาและกรองตามสัปดาห์ ระดับ และสถานะ
- แก้คำถาม ตัวเลือก เฉลย คำอธิบาย และคำอธิบายของตัวเลือกผิด (ดูตัวอย่างพร้อมสูตรได้ก่อนบันทึก)
- ปิด/เปิดใช้งานข้อสอบ และเพิ่มข้อสอบใหม่

ข้อสอบที่ครูแก้ไขแล้วจะไม่ถูกเขียนทับเมื่อมีการอัปเดตเนื้อหา

## 8. ส่งออกรายงาน

เมนู **ส่งออกรายงาน**:
- **สมุดคะแนน (Gradebook):** เลขประจำตัว ชื่อ ความก้าวหน้า การจบแต่ละสัปดาห์ คะแนนก่อน/หลังเรียน ห้องทดลอง คะแนนใบงาน ผลประเมินสมรรถนะ และ XP
- **วิเคราะห์ข้อสอบรายข้อ:** ทุกสัปดาห์

เลือก Excel (.xlsx) หรือ CSV (UTF-8 มี BOM เปิดภาษาไทยใน Excel ได้ทันที)

## 9. โหมดดูตัวอย่างของครู

ครูเปิดบทเรียนได้ทุกสัปดาห์โดยไม่ติดล็อก หน้าบทเรียนแสดงแถบ “โหมดดูตัวอย่างสำหรับครู” และ “บันทึกสำหรับครู” (ข้อแนะนำการสอน ข้อผิดพลาดที่พบบ่อย ประเด็นความปลอดภัย) คำตอบที่ครูกดในโหมดนี้ไม่ถูกบันทึกเป็นข้อมูลของนักเรียน

## 10. แรงจูงใจ (XP และเหรียญรางวัล)

นักเรียนได้ XP จากการแสดงความเข้าใจเท่านั้น (ตอบถูกในครั้งแรก, ผ่านขั้นฝึกปฏิบัติ, ภารกิจห้องทดลอง, ผ่านแบบทดสอบ, ภารกิจท้าทาย, ใบงานได้ระดับ ≥ 3, จบสัปดาห์) ไม่มี XP จากการเปิดหน้าหรือเวลาที่อยู่ในหน้า ไม่มีตารางจัดอันดับ

ระดับ: ช่างฝึกหัด (0) → ช่างผู้ช่วย (400) → ช่างเทคนิค (1,200) → ช่างชำนาญการ (2,600) → ผู้เชี่ยวชาญ (4,200 XP)

เหรียญรางวัล 10 แบบ เช่น Circuit Analyst (จบสัปดาห์ 3–5 แบบทดสอบ ≥ 80 %), Component Expert (สัปดาห์ 7–10 และ 13 แบบทดสอบ ≥ 80 %), Measurement Specialist (จบสัปดาห์ 17–18 และห้องทดลองมัลติมิเตอร์/ออสซิลโลสโคป), Electronics Explorer (ทำห้องทดลองครบทุกชุด), Growth Mindset (สอบผ่านหลังจากเคยไม่ผ่าน)

## 11. ข้อควรรู้เกี่ยวกับเนื้อหา

- เนื้อหาพัฒนาจากแผนการจัดการเรียนรู้ 15 หน่วย โดยแก้ข้อผิดพลาดในต้นฉบับ ปรับค่าระบบไฟฟ้าเป็น 230/400 V 50 Hz ปรับการปฐมพยาบาลให้เป็นปัจจุบัน และเขียนภาพใหม่ทั้งหมด รายละเอียดอยู่ใน `docs/curriculum/CURRICULUM_REPORT.md`
- มีประเด็นที่ครู/สถานศึกษาควรตัดสินใจ (หัวข้อ 8 ของรายงาน) เช่น การยืนยันข้อกำหนดตามมาตรฐาน วสท. ฉบับล่าสุดที่สถานศึกษาใช้ และตารางรหัสสีแถบความคลาดเคลื่อนสีเทา (หลักสูตรใช้ ±0.05 % ตามแบบที่ผู้ผลิตส่วนใหญ่ใช้ และอธิบายความต่างกับ IEC 60062:2016 ไว้ในบทเรียน)
- ห้องทดลองเสมือนเป็นแบบจำลองที่ระบุข้อสมมติไว้ทุกชุด ใช้เพื่อเข้าใจหลักการก่อนปฏิบัติจริง ไม่ใช่ตัวแทนการฝึกทักษะกับเครื่องมือจริง

## 12. สมรรถนะ 4 ด้าน (มุมมองจากหลักฐานการเรียน)

นอกจากสมรรถนะรายวิชา C1–C4 และการประเมินปลายภาคที่ครูบันทึกเองในเมนู “ประเมินสมรรถนะ” (ซึ่งยังเป็นผลอย่างเป็นทางการตามหลักสูตร) ระบบคำนวณ **มุมมองเพิ่มเติม 4 ด้าน** จากหลักฐานการเรียนให้โดยอัตโนมัติ และแสดงแยกกันชัดเจนเป็น 2 กลุ่มเสมอ:

- **จากกิจกรรมและห้องทดลองเสมือน** — หลักฐานอัตโนมัติ (แบบฝึกเชิงโต้ตอบ ห้องทดลองเสมือน แบบทดสอบ ภารกิจท้าทาย) ไม่ใช่ผลการปฏิบัติจริง
- **ผลปฏิบัติจริงที่ครูบันทึก** — เกณฑ์ความปลอดภัยในใบงานที่ครูให้คะแนน สมรรถนะ C1–C4 และการประเมินปลายภาค

| ด้าน | หลักฐานจากกิจกรรม/ห้องทดลองเสมือน (นับเฉพาะรายการที่นักเรียน **ลองทำแล้ว**) |
| --- | --- |
| 1 ความรู้และความเข้าใจ | คะแนนสูงสุดแบบทดสอบหลังเรียนแต่ละสัปดาห์ (น้ำหนัก = จำนวนข้อที่สุ่ม) และกิจกรรมเลือกตอบ/ทำนาย/จับคู่/เรียงลำดับ/จำแนก — นับว่าได้เมื่อ **ตอบถูกครั้งแรก** |
| 2 ทักษะการคำนวณและวิเคราะห์ | โจทย์เติมตัวเลข (ตอบถูกในที่สุด) ภารกิจห้องทดลองแบบตัวเลข และข้อสอบคำนวณในแบบทดสอบหลังเรียน (ทุกครั้งที่ส่ง) |
| 3 ทักษะการทดลองและแก้ปัญหา | ภารกิจปฏิบัติในห้องทดลองเสมือน (ตรวจสถานะวงจร) กิจกรรมชี้จุด/หาจุดบกพร่อง/สถานการณ์ และภารกิจท้าทาย (ได้ 1 เมื่อทำสำเร็จ, 0 เมื่อลองแล้วยังไม่สำเร็จ) |
| 4 ความปลอดภัยและกระบวนการปฏิบัติงาน | สถานการณ์จำลองในสัปดาห์ความปลอดภัย/การป้องกัน (W1–W2, W6) กิจกรรมที่ผูกกับจุดประสงค์ด้านคุณลักษณะ (รหัส …-A1, A2) และกิจกรรมที่โจทย์กล่าวถึง “ปลอดภัย”/“อันตราย” |

กลุ่ม **ปฏิบัติจริง (ครูประเมิน)** ของด้านที่ 4 คำนวณจากเกณฑ์ในใบงานที่มีคำว่า “ปลอดภัย” (ระดับ 1–4 ÷ 4) เฉพาะใบงานที่ให้คะแนนแล้ว

- ร้อยละของแต่ละด้าน = ค่าเฉลี่ยของรายการหลักฐาน (0 หรือ 1 ต่อรายการ; แบบทดสอบใช้ร้อยละ × จำนวนข้อ) และตัวเลข “หลักฐาน n รายการ” บอกว่าข้อมูลมากน้อยเพียงใด ร้อยละสูงแต่หลักฐานน้อยจึงยังไม่ควรสรุป
- **ต่ำกว่า 60 % = “ยังไม่ผ่านเกณฑ์”** แสดงเป็นข้อความกำกับแท่งทุกครั้ง (ไม่ใช้สีอย่างเดียว) และมีเส้นเกณฑ์ 60 % บนแท่ง
- หนึ่งกิจกรรมอาจนับได้หลายด้าน (เช่น สถานการณ์ความปลอดภัยนับทั้งด้าน 3 และ 4)
- นักเรียนเห็นมุมมองนี้ในแดชบอร์ด ครูเห็นในหน้ารายละเอียดนักเรียนพร้อมหัวข้อ **“ทักษะที่ยังไม่ผ่านเกณฑ์”** ได้แก่ ด้านที่ต่ำกว่า 60 % และจุดประสงค์การเรียนรู้ที่นักเรียนตอบผิดตั้งแต่ 2 ครั้งโดยยังไม่เคยตอบถูก (ใช้วางแผนสอนซ่อมเสริมรายบุคคล)
- หน้า “ภาพรวมห้องเรียน” มีตารางค่าเฉลี่ยของห้องแต่ละด้านและจำนวนนักเรียนที่ต่ำกว่า 60 %
- ในสมุดคะแนน (Gradebook) คอลัมน์ขึ้นต้นด้วย **“จำลอง:”** คือค่าจากกิจกรรม/ห้องทดลองเสมือน และ **“ปฏิบัติจริง:”** คือผลที่ครูบันทึก — ไม่ควรนำมารวมกันเป็นคะแนนเดียว
- หน้าบทนำและหน้าสรุปของทุกสัปดาห์มีกล่อง “เกณฑ์การผ่านสัปดาห์นี้ / เกณฑ์ประเมินสมรรถนะ” ที่บอกนักเรียนว่าต้องทำอะไรให้ครบ เกณฑ์ผ่านแบบทดสอบ ใบงานพร้อมเกณฑ์ให้คะแนน สมรรถนะ C1–C4 ที่สัปดาห์นั้นสนับสนุน และหลักฐานของสัปดาห์นับเข้าด้านใดบ้าง (รายละเอียดการจับคู่อยู่ในไฟล์ `src/lib/competency-domains.ts`)
