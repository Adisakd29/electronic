# PROJECT: Interactive Electrical & Electronics Learning Platform

## 1. บทบาทและเป้าหมายโครงการ

คุณคือทีมผู้เชี่ยวชาญประกอบด้วย

- Senior Full-Stack Web Developer
- UI/UX Designer ผู้เชี่ยวชาญเว็บไซต์เพื่อการศึกษา
- Instructional Designer ด้านการจัดการเรียนรู้ระดับอาชีวศึกษา
- Electrical & Electronics Engineering Instructor
- Interactive Simulation Developer
- Educational Content Quality Assurance Specialist

ฉันต้องการให้คุณพัฒนาเว็บไซต์สำหรับจัดการเรียนการสอนรายวิชา **งานไฟฟ้าและอิเล็กทรอนิกส์เบื้องต้น รหัสวิชา 20100-1005** สำหรับนักเรียนระดับประกาศนียบัตรวิชาชีพ (ปวช.)

เว็บไซต์ต้องเป็นระบบการเรียนรู้ออนไลน์เต็มรูปแบบที่ทันสมัย มีเนื้อหาวิชาการครบถ้วน ภาพประกอบสวยงาม ถูกต้องตามหลักวิศวกรรม มีกิจกรรมเชิงโต้ตอบ ห้องทดลองเสมือนจริง แบบฝึกหัด และระบบประเมินผล

**เป้าหมายสำคัญ:** นักเรียนที่เรียนครบ 18 สัปดาห์ต้องสามารถอธิบายหลักการพื้นฐานของไฟฟ้าและอิเล็กทรอนิกส์ วิเคราะห์วงจรเบื้องต้น เลือกใช้อุปกรณ์ วัดค่าทางไฟฟ้า และประยุกต์ความรู้ในการปฏิบัติงานภายใต้หลักความปลอดภัยได้

ห้ามสร้างเว็บไซต์ที่มีเพียงหัวข้อบทเรียนหรือข้อความสรุปสั้น ๆ เนื้อหาต้องมีคุณภาพเพียงพอสำหรับใช้จัดการเรียนการสอนจริง

## 2. วิเคราะห์เอกสารที่แนบมาทั้งหมดก่อนเริ่มพัฒนา

ฉันแนบไฟล์ ZIP ซึ่งประกอบด้วยแผนการจัดการเรียนรู้ และบทเรียนที่ 1–15

ให้ดำเนินการดังนี้

1. อ่านและวิเคราะห์เอกสาร Word ทุกไฟล์โดยละเอียด รวมถึงตาราง รูปภาพ แผนผังวงจร ตัวอย่าง แบบฝึกหัด และจุดประสงค์การเรียนรู้
2. ใช้เอกสารที่แนบเป็นโครงสร้างเนื้อหาหลักของหลักสูตร
3. รักษาสาระสำคัญและสมรรถนะรายวิชาให้ครบถ้วน
4. ตรวจสอบความถูกต้องของคำอธิบาย สูตรคำนวณ หน่วย สัญลักษณ์ และตัวอย่าง
5. ตรวจหาเนื้อหาที่ผิดพลาด ล้าสมัย ซ้ำซ้อน หรือไม่ตรงกับชื่อบทเรียน แล้วปรับปรุงให้ถูกต้อง
6. เพิ่มเนื้อหาที่จำเป็นตามความเหมาะสม โดยไม่ทำให้หลักสูตรเบี่ยงเบนจากจุดประสงค์เดิม
7. นำภาพประกอบจากเอกสารมาใช้อย่างเหมาะสมเมื่อมีสิทธิใช้งาน และวาดภาพใหม่ในรูปแบบ SVG เมื่อจำเป็น เพื่อเพิ่มความคมชัดและความถูกต้อง
8. ตรวจสอบความสอดคล้องระหว่างเนื้อหา สมรรถนะ กิจกรรมการเรียนรู้ และการประเมินผล

กรณีข้อมูลในเอกสารต้นฉบับขัดแย้งกัน ให้ระบุสิ่งที่แก้ไขไว้ในรายงานการปรับปรุงหลักสูตร

อย่าคัดลอกข้อความที่ผิดพลาดจากเอกสารโดยไม่ตรวจทาน

## 3. โครงสร้างบทเรียน 18 สัปดาห์

จัดเว็บไซต์เป็น 18 สัปดาห์ สัปดาห์ละ 4 ชั่วโมง โดยมีทฤษฎี 1 ชั่วโมงและกิจกรรมปฏิบัติ 3 ชั่วโมง

| สัปดาห์ | หัวข้อหลัก |
|---|---|
| 1 | ระบบความปลอดภัยในการทำงานไฟฟ้าและอิเล็กทรอนิกส์ |
| 2 | การป้องกันอุบัติเหตุทางไฟฟ้าและการรับมือเหตุฉุกเฉิน |
| 3 | ความรู้เบื้องต้นเกี่ยวกับไฟฟ้าและวงจรไฟฟ้า |
| 4 | วงจรไฟฟ้าและการวัดค่าปริมาณทางไฟฟ้าเบื้องต้น |
| 5 | วงจรไฟฟ้าแสงสว่าง |
| 6 | อุปกรณ์ป้องกันไฟฟ้า |
| 7 | ตัวต้านทาน (Resistor) |
| 8 | ตัวเก็บประจุ (Capacitor) |
| 9 | ตัวเหนี่ยวนำ (Inductor) |
| 10 | หม้อแปลงไฟฟ้า (Transformer) |
| 11 | รีเลย์ (Relay) |
| 12 | ไมโครโฟนและลำโพง |
| 13 | อุปกรณ์สารกึ่งตัวนำ |
| 14 | เทคนิคการบัดกรีและการประกอบวงจรอิเล็กทรอนิกส์ ตอนที่ 1 |
| 15 | การประกอบ ตรวจสอบ และแก้ไขข้อบกพร่องของวงจร ตอนที่ 2 |
| 16 | การควบคุมมอเตอร์เบื้องต้น |
| 17 | เครื่องมือวัดและทดสอบทางไฟฟ้า ตอนที่ 1 |
| 18 | เครื่องมือวัดและทดสอบทางไฟฟ้า ตอนที่ 2 พร้อมประเมินสมรรถนะปลายภาค |

สามารถปรับหัวข้อย่อยและการกระจายเนื้อหาภายในแต่ละสัปดาห์ได้ตามความเหมาะสม แต่ต้องรักษาครบทั้ง 15 หน่วยการเรียนรู้จากเอกสารต้นฉบับและครอบคลุมเวลา 18 สัปดาห์

เนื้อหาควรเริ่มจากง่ายไปยากและมีความต่อเนื่องกัน

## 4. มาตรฐานเนื้อหาที่ต้องมีในทุกสัปดาห์

ทุกสัปดาห์ต้องประกอบด้วยส่วนสำคัญต่อไปนี้

### A. Learning Objectives

แสดงจุดประสงค์การเรียนรู้เชิงพฤติกรรมที่วัดผลได้ แยกด้านความรู้ ทักษะ และคุณลักษณะที่พึงประสงค์

### B. Introduction

มีบทนำที่เชื่อมโยงเนื้อหากับสถานการณ์จริง พร้อมภาพประกอบที่เหมาะสม เพื่อกระตุ้นความสนใจของนักเรียน

### C. Comprehensive Learning Content

เนื้อหาแต่ละสัปดาห์ต้องละเอียด ครบถ้วน และอ่านเข้าใจง่าย

อธิบายตั้งแต่แนวคิดพื้นฐาน หลักการทำงาน สัญลักษณ์ทางไฟฟ้า สูตรคำนวณ ตัวอย่างการประยุกต์ใช้งาน และข้อจำกัดของอุปกรณ์ตามหัวข้อนั้น

ไม่กำหนดจำนวนหัวข้อย่อยตายตัว ให้แบ่งตามความเหมาะสมของเนื้อหา

ข้อกำหนด:
- ใช้ภาษาไทยเป็นหลักพร้อมศัพท์เทคนิคภาษาอังกฤษ
- อธิบายศัพท์สำคัญเมื่อปรากฏครั้งแรก
- มีตัวอย่างการคำนวณที่อธิบายทีละขั้นตอน
- ตรวจสอบคำตอบ สูตร และหน่วยทุกครั้ง
- แบ่งเนื้อหาเป็นหน้าหรือ Step ที่เรียนได้ง่าย ไม่แสดงข้อความยาวทั้งหมดในหน้าเดียว
- มีภาพประกอบสำหรับแนวคิดที่ต้องการการอธิบายด้วยภาพ
- เพิ่มเนื้อหาที่เป็นประโยชน์จากแหล่งข้อมูลทางวิชาการที่เชื่อถือได้

ห้ามใช้ข้อความ Placeholder หรือเนื้อหาซ้ำเพื่อให้ดูเหมือนว่าบทเรียนมีความยาว

### D. Visual Learning

ออกแบบภาพประกอบคุณภาพสูง เช่น

- ภาพโครงสร้างอุปกรณ์ไฟฟ้าและอิเล็กทรอนิกส์
- ภาพวงจรไฟฟ้าแบบ Schematic
- ภาพแสดงทิศทางกระแสและความแตกต่างศักย์
- กราฟแรงดัน กระแส และสัญญาณตามเวลา
- ภาพแสดงการต่ออุปกรณ์บน Breadboard แรงดันต่ำ
- ภาพเปรียบเทียบอุปกรณ์ชนิดต่าง ๆ
- Infographic สรุปเนื้อหาสำคัญ
- Animation แสดงหลักการทำงาน

ใช้ SVG, Canvas หรือเทคโนโลยีอื่นตามความเหมาะสม

ภาพต้องมีสัดส่วนถูกต้อง อ่านป้ายกำกับได้ชัดเจนบนมือถือ และต้องไม่ใช้ภาพตกแต่งที่ไม่เกี่ยวข้องกับเนื้อหา

### E. Interactive Learning

ทุกสัปดาห์ต้องมีปฏิสัมพันธ์กับผู้เรียน เช่น

- คลิกอุปกรณ์เพื่อดูชื่อและหน้าที่
- ลากคำศัพท์ไปจับคู่กับสัญลักษณ์
- เลือกคำตอบระหว่างอ่านบทเรียน
- เติมค่าที่หายไปในสมการ
- ทำนายผลก่อนแสดงคำตอบ
- ค้นหาข้อผิดพลาดในวงจร
- เรียงลำดับกระบวนการ
- วิเคราะห์สถานการณ์จริง

เมื่อตอบผิด ให้มีคำอธิบายว่าผิดเพราะอะไร แทนการแสดงเพียงเครื่องหมายผิด

### F. Worked Examples

มีตัวอย่างพร้อมเฉลยอย่างเป็นขั้นตอนอย่างน้อย 3 ตัวอย่างต่อสัปดาห์ เมื่อเนื้อหาเหมาะสมกับการคำนวณหรือวิเคราะห์

### G. Practice Activities

สร้างกิจกรรมฝึกทักษะที่หลากหลาย โดยกำหนดจุดประสงค์ อุปกรณ์หรือสื่อที่ต้องใช้ ภารกิจ เกณฑ์ประเมิน และผลลัพธ์ที่คาดหวัง

### H. Weekly Assessment

มีแบบทดสอบท้ายสัปดาห์ประมาณ 10–15 ข้อ โดยผสมข้อสอบวัดความจำ ความเข้าใจ การประยุกต์ใช้ และการวิเคราะห์

ต้องมีคลังข้อสอบและสุ่มโจทย์เพื่อไม่ให้ผู้เรียนพบข้อสอบชุดเดิมทุกครั้ง

### I. Summary & Review

มีสรุปความรู้ แผนผังความคิด สูตรสำคัญ และคำศัพท์ท้ายบท

### J. Learning Resources

เพิ่มแหล่งเรียนรู้เพิ่มเติมที่ตรวจสอบได้ โดยไม่ใช้ลิงก์สมมติ

## 5. พัฒนาห้องทดลองเสมือนจริง (Virtual Laboratory)

นี่คือหนึ่งในฟีเจอร์ที่สำคัญที่สุดของเว็บไซต์

ต้องการให้ผู้เรียนทดลองและสังเกตปรากฏการณ์ทางไฟฟ้าผ่านเว็บไซต์ได้จริง ไม่ใช่เพียงดูภาพนิ่ง

ตัวอย่าง Simulation ที่ควรพัฒนา ได้แก่

**Circuit Simulator**
จำลองวงจรไฟฟ้ากระแสตรงแรงดันต่ำ ให้นักเรียนเปลี่ยนค่าความต้านทาน แรงดัน และรูปแบบการต่อวงจร แล้วดูการเปลี่ยนแปลงของกระแสและแรงดัน

**Ohm's Law Laboratory**
ปรับค่า V, I และ R พร้อมแสดงความสัมพันธ์ผ่านกราฟและเครื่องมือวัดเสมือน

**Resistor Color Code**
ฝึกอ่านแถบสีตัวต้านทานและคำนวณค่าความต้านทานพร้อมค่าความคลาดเคลื่อน

**Capacitor Simulator**
จำลองการเปลี่ยนแปลงแรงดันระหว่างการประจุและคายประจุ โดยแสดงกราฟตามเวลา

**Inductor & Transformer Visualization**
แสดงผลของสนามแม่เหล็กและความสัมพันธ์พื้นฐานของหม้อแปลงในแบบจำลองที่ปรับค่าได้

**Relay Simulator**
จำลองสถานะหน้าสัมผัส NO/NC และการควบคุมวงจรแรงดันต่ำ

**Semiconductor Laboratory**
จำลองลักษณะการทำงานพื้นฐานของไดโอด LED และทรานซิสเตอร์

**Motor Control Simulator**
จำลองการควบคุมมอเตอร์ DC แรงดันต่ำและผลของการปรับค่าตัวแปร

**Virtual Multimeter**
แสดงหน้าจอเครื่องวัดแบบดิจิทัล พร้อมโจทย์การตีความค่าที่วัดได้

**Virtual Oscilloscope**
แสดงคลื่นสัญญาณ สามารถปรับ Time/Div และ Volt/Div เพื่อฝึกอ่านค่าจากหน้าจอ

ทุก Simulation ต้องมีวัตถุประสงค์ ภารกิจ คำแนะนำ คำถาม และระบบตรวจผลลัพธ์

หากแบบจำลองเป็นเพียงการประมาณค่า ให้ระบุข้อสมมติและขอบเขตความแม่นยำอย่างชัดเจน อย่าแสดงผลลัพธ์ที่ขัดกับหลักวิศวกรรม

กิจกรรมจำลองต้องเน้นความปลอดภัย ใช้วงจรแรงดันต่ำและไม่เปิดโอกาสให้ทดลองกับไฟฟ้าจากเต้ารับจริงผ่านคำแนะนำบนเว็บไซต์ ส่วนการปฏิบัติกับอุปกรณ์ที่มีความร้อน ไฟฟ้าแรงสูง หรือความเสี่ยงอื่น ต้องระบุให้เป็นกิจกรรมภายใต้การควบคุมของครูและมาตรการความปลอดภัยที่เหมาะสม

## 6. ระบบการเรียนรู้ทีละขั้นตอน

ออกแบบ Learning Path ที่มีขั้นตอนดังนี้

Introduction → Learn → Interactive Practice → Virtual Lab → Weekly Quiz → Complete

เมื่อผ่านแต่ละขั้นตอนให้บันทึกความก้าวหน้าโดยอัตโนมัติ

นักเรียนสามารถกลับมาทบทวนบทเรียนเดิมได้ทุกเวลา และกลับมาเรียนต่อจากตำแหน่งล่าสุดได้

เพิ่มระบบปลดล็อกสัปดาห์ถัดไปตามเกณฑ์ที่ครูกำหนด เช่น

- เรียนเนื้อหาที่กำหนดครบ
- ผ่านกิจกรรมสำคัญ
- ส่งใบงานหรือผลการทดลอง
- ผ่านแบบทดสอบตามคะแนนขั้นต่ำ

ครูต้องสามารถเปิดหรือปิดระบบล็อกบทเรียน ปรับเกณฑ์ และปลดล็อกให้นักเรียนรายบุคคลได้

แบ่งบัญชีผู้ใช้งานเป็น Student, Teacher และ Administrator

**Student Dashboard**

แสดงสัปดาห์ที่กำลังเรียน ความก้าวหน้า คะแนน ใบงานที่ต้องส่ง บทเรียนที่ปลดล็อก และประวัติการเรียน

**Teacher Dashboard**

ครูสามารถดูข้อมูลภาพรวมของห้องเรียน ได้แก่

- จำนวนนักเรียนที่เริ่มเรียนและเรียนจบแต่ละสัปดาห์
- ความก้าวหน้ารายบุคคล
- คะแนนแบบทดสอบก่อนเรียนและหลังเรียน
- คำถามที่นักเรียนตอบผิดบ่อย
- ผลการทำ Virtual Lab
- งานที่ส่งและงานที่ยังไม่ส่ง
- ผลประเมินสมรรถนะ
- รายงานผลการเรียนที่ส่งออกเป็น CSV หรือ Excel ได้

เพิ่มระบบจัดกลุ่มนักเรียนตามห้องเรียนและภาคเรียน

รองรับการเข้าสู่ระบบด้วย Google และบัญชีที่ได้รับอนุญาต โดยใช้ระบบ Authentication ที่ปลอดภัย พร้อมการกำหนดสิทธิ์การเข้าถึงข้อมูลให้เหมาะสม

ไม่จัดเก็บข้อมูลส่วนบุคคลเกินความจำเป็น

## 8. การออกแบบ UI/UX

ต้องการเว็บไซต์ที่ทันสมัย สีสันสดใส อ่านง่าย และเหมาะกับนักเรียนอาชีวศึกษา

ใช้แนวคิด **Modern Engineering Education Platform**

แนวทางการออกแบบ:

- รูปแบบ Clean, Modern และ Interactive
- ใช้สีอย่างมีระบบ แบ่งสีตามหมวดเนื้อหา
- ใช้ฟอนต์ภาษาไทยที่อ่านง่ายและมีขนาดเหมาะสม
- มีภาพประกอบคุณภาพสูง
- ใช้ไอคอน SVG แทนอีโมจิเป็นหลัก
- มี Animation และ Micro-interaction ที่ช่วยให้เข้าใจเนื้อหา
- รองรับ Light Mode และ Dark Mode
- มี Sidebar แสดง 18 สัปดาห์
- มี Progress Indicator
- Responsive สำหรับคอมพิวเตอร์ แท็บเล็ต และมือถือ
- รองรับการใช้งานด้วยคีย์บอร์ดและมีคำอธิบายภาพสำหรับการเข้าถึง

หลีกเลี่ยงการใช้ตัวอักษรขนาดเล็ก ข้อความยาวที่จัดวางแน่น หรือ Animation ที่รบกวนการอ่าน

หน้าแรกควรมี Course Overview, Learning Roadmap, Learning Outcomes และปุ่มเข้าสู่บทเรียน

## 9. Gamification

เพิ่มระบบสร้างแรงจูงใจโดยไม่ทำให้เกมบดบังเป้าหมายการเรียนรู้

ระบบที่ต้องการ ได้แก่ XP, Level, Achievement, Weekly Challenge และ Certificate of Completion

มอบรางวัลจากการแสดงความเข้าใจ การพัฒนาทักษะ และการทำกิจกรรมสำเร็จ ไม่ใช่เพียงการคลิกหรือใช้เวลาอยู่ในหน้าเว็บ

ควรมี Achievement เช่น Circuit Analyst, Component Expert, Measurement Specialist และ Electronics Explorer

ไม่จำเป็นต้องมีระบบแข่งขันจัดอันดับ หากไม่ช่วยเพิ่มคุณภาพการเรียนรู้

## 10. โครงสร้างทางเทคนิค

หากเป็นโครงการใหม่ ให้เลือก Technology Stack ที่ทันสมัย ดูแลรักษาง่าย และรองรับการใช้งานจริง

แนวทางที่พิจารณาได้ เช่น

Frontend: Next.js, React, TypeScript, Tailwind CSS

Backend/Database: PostgreSQL พร้อมระบบ Authentication และการกำหนดสิทธิ์

Interactive Graphics: SVG, Canvas, Web Animations หรือ Library ที่เหมาะสม

จัดเก็บเนื้อหาบทเรียนเป็นข้อมูลแบบมีโครงสร้าง แยกจากส่วนติดต่อผู้ใช้ เพื่อให้เพิ่มหรือแก้ไขบทเรียนได้ในอนาคต

ระบบต้องรองรับ:

- การบันทึกความก้าวหน้าแบบถาวร
- การเพิ่มและแก้ไขข้อสอบ
- การจัดเก็บผลการทำแบบทดสอบ
- การอัปโหลดใบงาน
- การจัดการบทเรียน
- การสำรองข้อมูล
- การนำไป Deploy บน Railway หรือ Hosting ที่เหมาะสม

ให้สร้างโค้ดที่มีโครงสร้างชัดเจน สามารถพัฒนาต่อได้จริง ไม่ใช่เพียง Prototype

## 11. ข้อกำหนดด้านคุณภาพที่ต้องตรวจสอบ

ก่อนส่งมอบ ให้ตรวจสอบอย่างน้อยดังนี้

1. มีบทเรียนครบ 18 สัปดาห์ และมีเนื้อหาจริงทุกสัปดาห์
2. เนื้อหาครอบคลุมสมรรถนะรายวิชาตามเอกสารแนบ
3. ไม่มีหัวข้อว่างหรือข้อความ Placeholder
4. รูปภาพ สัญลักษณ์ กราฟ และแผนผังวงจรแสดงผลถูกต้อง
5. สูตรคำนวณและเฉลยข้อสอบผ่านการตรวจทาน
6. Simulation ให้ผลลัพธ์สอดคล้องกับแบบจำลองที่ระบุ
7. ระบบคะแนนและความก้าวหน้าบันทึกได้จริง
8. นักเรียนไม่สามารถเข้าถึงข้อมูลส่วนตัวของนักเรียนคนอื่น
9. ระบบปลดล็อกบทเรียนทำงานถูกต้อง
10. เว็บไซต์ใช้งานได้ทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์
11. ไม่มีปุ่มที่กดแล้วไม่ทำงานหรือหน้าที่มีเพียงข้อมูลตัวอย่าง
12. ตรวจสอบ Error, Broken Links และปัญหาการแสดงผล
13. มีระบบแจ้งข้อผิดพลาดที่ผู้ใช้เข้าใจได้
14. จัดทำเอกสารการติดตั้ง การตั้งค่า และการ Deploy

## 12. ลำดับการดำเนินงาน

**Phase 1: Curriculum Analysis**

วิเคราะห์ไฟล์ทั้งหมด สร้าง Curriculum Mapping ของ 18 สัปดาห์ ตรวจสอบข้อผิดพลาดและเสนอการเพิ่มเติมเนื้อหา

**Phase 2: Website Architecture & UI Design**

ออกแบบฐานข้อมูล โครงสร้างเว็บไซต์ Navigation, Learning Path และ Component System

**Phase 3: Core Learning System**

พัฒนาระบบสมาชิก Dashboard ระบบบทเรียน ระบบความก้าวหน้า และระบบประเมินผล

**Phase 4: Complete Learning Content**

สร้างเนื้อหาครบทั้ง 18 สัปดาห์ พร้อมภาพประกอบ ตัวอย่าง แบบฝึกหัด และกิจกรรมในแต่ละสัปดาห์

**Phase 5: Interactive Simulations**

พัฒนาห้องทดลองเสมือนจริงและเชื่อมกับบทเรียนที่เกี่ยวข้อง

**Phase 6: Quality Assurance**

ทดสอบการทำงาน ตรวจสอบความถูกต้องทางวิชาการ และปรับปรุงประสบการณ์ใช้งาน

**Phase 7: Deployment**

เตรียมเว็บไซต์สำหรับใช้งานจริง พร้อมคู่มือการใช้งานสำหรับครูและนักเรียน

## 13. เงื่อนไขสำคัญที่สุด

ฉันให้ความสำคัญกับ **คุณภาพและความสมบูรณ์ของเนื้อหามากกว่าความรวดเร็วในการพัฒนา**

อย่าลดรายละเอียดของบทเรียนเพื่อให้ทำครบ 18 สัปดาห์อย่างรวดเร็ว

อย่าคัดลอกเนื้อหาเดิมซ้ำหลายสัปดาห์

อย่าสร้าง Simulation ที่เป็นเพียงภาพตกแต่งโดยไม่มีระบบจำลองที่ทำงานจริง

ทุกองค์ประกอบของเว็บไซต์ควรมีประโยชน์ต่อการเรียนรู้และสามารถนำไปใช้สอนนักเรียน ปวช. ในห้องเรียนจริงได้

**เริ่มต้นด้วยการวิเคราะห์เอกสาร ZIP ทั้งหมด และจัดทำแผนพัฒนาเว็บไซต์ที่เชื่อมโยงเนื้อหา 15 หน่วยเดิมเข้ากับ 18 สัปดาห์ จากนั้นดำเนินการพัฒนาเว็บไซต์ตามแผน โดยตรวจสอบความสมบูรณ์ในแต่ละ Phase ก่อนทำ Phase ถัดไป**

หากมีส่วนที่ยังพัฒนาไม่ครบ ให้รายงานสถานะตามความเป็นจริง ห้ามระบุว่าเว็บไซต์เสร็จสมบูรณ์จนกว่าจะผ่านการตรวจสอบตามเกณฑ์ทั้งหมด
