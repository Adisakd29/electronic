## Routes
- `/` home: course overview (code, name, credits, 18 weeks × 4 h, description), the PCB roadmap of 18 weeks (title, category, focus on hover/focus; links), learning outcomes & 4 competencies, how a week works (the 6-stage path), the 10 virtual labs teaser (from `labCatalog`), CTA: signed-out → "เข้าสู่ระบบเพื่อเริ่มเรียน" (/login); signed-in → "เรียนต่อ สัปดาห์ที่ N" (resume). The static parts must prerender; the CTA reads the session in Suspense.
- `/learn` → redirect to the current week/stage (resume position) for signed-in users; `/login?next=/learn` otherwise.
- `/learn/[week]` → redirect to the resume stage for that week (or `intro`).
- `/learn/[week]/[stage]` stage ∈ intro|learn|practice|lab|quiz|complete. Learn stage step index via `?step=N` (client state synced to URL; also store via `savePosition`). Locked week (from `getWeekProgress().unlocked=false`) → locked screen showing `lockReason` and a link to the previous week. Teachers/admins see a "โหมดดูตัวอย่างสำหรับครู" banner; their interactions don't write progress (actions no-op for staff) and teacher notes are visible to them only.
- `/learn/[week]/worksheet/[activityId]` printable worksheet (A4 print CSS: header with course/week/name/class/date fields, objective, equipment, safety notes, procedure, blank recording table with `rows`, questions with answer lines, rubric table) + upload form (`submitAssignment`) on screen only.
- `/labs` gallery of 10 labs (catalog), `/labs/[id]` free-play lab with preset picker, assumptions panel, and links to the weeks that use it (no task tracking). Labs are prerenderable; the lab component loads client-side.
- `/dev/lesson` (only when `process.env.NODE_ENV === "development"`; `notFound()` otherwise): renders a fixture week `src/app/dev/fixture-week.ts` that exercises EVERY block type and EVERY interaction kind with mock progress, so the integrator can visually test the player without auth or DB.

## Lesson player (client) — behaviour
- Server page loads the static `Week` from `getWeek(n)` and, inside Suspense, `getWeekProgress(n)` + `getSessionUser()`; passes serialisable props to a client `LessonPlayer`.
- Top: week title with category colour bar, stepper (6 stages; done ✓, current, locked-for-now stages still navigable but marked), overall week progress. Sidebar (shell): 18 weeks with category chip, progress ring, lock icon + tooltip with reason; current week expanded with stage links; collapses to a drawer on mobile (≤ 1024 px), focus-trapped, Escape closes.
- **Intro**: learning objectives grouped knowledge/skill/attitude, hook + scenario + figure, why it matters, prior knowledge, warm-up interactions, optional pre-test (`startQuiz(week,"pre")`, 5 questions, shown once, "ข้าม" allowed), then "เริ่มเรียน" → `completeStage(week,"intro")`.
- **Learn**: one step per page, step list with ticks, prev/next, estimated minutes; render blocks; "ทำขั้นนี้เสร็จแล้ว" → `markStepComplete`; when all steps done → `completeStage(week,"learn")`. Inline interactions record via `recordInteraction`. Embedded `{type:"lab"}` blocks lazy-load the lab in compact mode.
- **Practice**: the `practice` interactions in sequence with a progress counter; each must be answered correctly at least once (retry allowed; after 2 wrong tries offer "ดูคำอธิบาย"); worked examples section (accordion, reveal steps one by one, then `tryIt`); complete when all correct → `completeStage(week,"practice")`.
- **Lab**: `LabRunner` = lab component (lazy via `labLoaders`, preset from week) + task panel: numeric tasks (input with unit, tolerance), mcq tasks, state tasks ("ตรวจสอบ" evaluates `lab.checks[check].fn(latestState, params)`); each result → `recordLabTask`; hints, explanation after success; assumptions (lab module + week); instructions; reflection questions (textarea → `saveLabReflection`); complete when all tasks done → `completeStage(week,"lab")`. Below: the hands-on practice activities (ใบงาน) with safety level badge (S0–S3 with Thai meaning; S2/S3 show "ต้องอยู่ภายใต้การควบคุมของครู"), link to printable worksheet + upload status.
- **Quiz**: start/resume via `startQuiz(week,"post")`; one question per screen or full list (toggle), autosave answers (`saveQuizAnswers`, debounced), progress, submit confirmation, results with score, pass/fail vs passPercent, per-question review (your answer, correct answer, explanation, why your choice was wrong), XP/achievement toasts, retry button (new random draw), next week unlocked notice.
- **Complete**: summary key points, mind map (render as an SVG radial/tree diagram from `summary.mindmap`, readable on mobile), formulas (KaTeX), vocabulary table (searchable), safety review box, resources list (external links open in new tab with rel="noopener"), weekly challenge (render the challenge interaction; on correct → `completeChallenge`), "จบบทเรียนสัปดาห์นี้" → `completeStage(week,"complete")` (enabled when prior stages done; otherwise list what's missing), link to next week.
- Autosave position on stage/step change (`savePosition`). Return to the last position on revisit. Everything works with keyboard only.

- Toast XP / achievements from action results.

## Quality floor
Responsive 360 px → desktop; visible focus rings; `prefers-reduced-motion` respected; colour never the only signal; aria-live for check results; all buttons do something; Thai copy in plain active voice ("ตรวจคำตอบ", "ลองอีกครั้ง", "ไปขั้นต่อไป"); error states explain what happened and what to do (action `ok:false` → inline Alert with `error`); loading skeletons for Suspense fallbacks; no layout shift for figures (reserve aspect ratio from viewBox when known). Print styles for worksheets and the summary page. Dark mode correct everywhere (tokens only).
