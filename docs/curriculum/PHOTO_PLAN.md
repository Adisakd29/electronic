# แผนใส่ภาพถ่ายของจริง (20 ต.ค. 2569)

คำขอ: "ใช้ภาพจริงแทนการวาดรูปขึ้นมาในอุปกรณ์ที่มีจริงทุกหน่วย"

## สถานะ (21 ต.ค. 2569)

- **ใส่แล้ว 40 จาก 43 ภาพ** ทุกภาพมาจาก Wikimedia Commons ใช้สัญญาอนุญาต CC0, สาธารณสมบัติ, CC BY หรือ CC BY-SA มีชื่อผู้ถ่ายและลิงก์ต้นฉบับใต้ภาพและที่หน้า `/credits` ทุกภาพเปิดดูด้วยตาแล้ว และแก้คำบรรยายภาพ (alt) ให้ตรงกับที่เห็นในภาพจริง
- **แทนภาพวาด 1 ภาพ** (W18-F05 สโคปอะนาล็อก) ส่วนอีก 39 ภาพ **แสดงคู่กับภาพวาด** เพราะภาพวาดมีป้ายชื่อ ภาพตัด ตาราง หรือพิกัดกิจกรรมหาจุดที่ภาพถ่ายให้ไม่ได้
  - เดิมวางแผนให้แทนภาพวาด 6 ภาพ แต่เมื่อดูภาพจริงแล้ว 5 ภาพยังต้องเก็บภาพวาดไว้ ได้แก่ W07-F03 (หาได้เฉพาะภาพตัวต้านทานปรับค่าได้), W08-F03 (ภาพวาดมีป้ายบอกว่ามีขั้วหรือไม่มีขั้ว), W11-F10 (ภาพวาดแสดงวงจรภายในโมดูล), W14-F12 (หาภาพแผ่นอเนกประสงค์ทั้ง 3 แบบไม่ได้) และ W14-F05 (ดูข้อถัดไป)
- **ยังไม่มีภาพถ่าย 3 ภาพ (ใช้ภาพวาดเดิม):**
  - W05-F04 หลอดฟลูออเรสเซนต์และบัลลาสต์แกนเหล็ก: ภาพที่พบยืนยันไม่ได้ว่าเป็นบัลลาสต์แกนเหล็ก
  - W12-F06 ลำโพงด้านหลัง: ภาพที่พบมืดเกินไป
  - W14-F05 ปลายหัวแร้งหลายรูปทรง: ภาพที่พบเป็นภาพเรนเดอร์ 3 มิติ ไม่ใช่ภาพถ่าย
  - ถ้าโรงเรียนถ่ายภาพเองได้ ใส่ด้วย `license: "School owned"`
- ข้อสังเกตของภาพที่ใส่แล้ว:
  - W05-F05 เป็นหลอด LED ขั้วเขี้ยว B22 ไม่ใช่ E27 (คำบรรยายระบุไว้แล้ว)
  - W07-F02 เป็นภาพเล็ก (269 px) เพราะต้นฉบับเป็นภาพแนวยาวมาก

## หลักการ

1. ใช้เฉพาะภาพที่มีสัญญาอนุญาตแบบเปิดบน Wikimedia Commons (CC0, สาธารณสมบัติ, CC BY, CC BY-SA) หรือภาพที่โรงเรียนถ่ายเอง ห้ามใช้ภาพจากร้านค้า บล็อก หรือผลค้นหารูปทั่วไป
2. ทุกภาพต้องเปิดดูด้วยตาก่อนใส่ ว่าแสดงอุปกรณ์ที่ตรงกับบทเรียนจริง (เช่น เต้ารับต้องเป็นแบบ มอก. 166-2549 ไม่ใช่แบบประเทศอื่น)
3. ลดขนาดเป็นด้านยาว ≤ 1600 px แปลงเป็น JPEG/WebP เก็บที่ `public/photos/<KEY>.jpg` และบันทึกการแก้ไขใน `modified`
4. **แทนที่ภาพวาด (`replace`)** เฉพาะภาพที่แค่แสดงหน้าตาอุปกรณ์และใช้ในเนื้อหาบทเรียนเท่านั้น
5. **แสดงคู่กัน (`with`)** เมื่อภาพวาดมีสิ่งที่ภาพถ่ายให้ไม่ได้ ได้แก่ ป้ายชื่อส่วนประกอบ ภาพตัด ตารางรหัส หรือเป็นภาพของกิจกรรมหาจุด (hotspot/findFault) ที่คำตอบผูกกับพิกัดบนภาพวาด validator บังคับข้อนี้
6. แผนภาพวงจร สัญลักษณ์ กราฟ รูปคลื่น ผังขั้นตอน และหน้าปัดฝึกอ่าน **คงเป็นภาพวาด** เพราะไม่ใช่ภาพของอุปกรณ์

## ขั้นตอนเมื่อเปิดสิทธิ์แล้ว

1. ค้นใน Commons API (`list=search`, namespace 6) แล้วอ่าน `imageinfo` + `extmetadata` (LicenseShortName, Artist, ImageDescription)
2. ดาวน์โหลดไฟล์ขนาด 1600 px (`iiurlwidth=1600`) ลงโฟลเดอร์แยก เปิดดูด้วยตา คัดภาพที่ตรงที่สุด
3. ใส่รายการใน `photos.ts` (ผู้ถ่ายตาม Artist แบบข้อความล้วน, สัญญาอนุญาตตรงตาม LicenseShortName)
4. `npm run content:check -- --all`, build, e2e, ตรวจหน้าเว็บด้วยตาทั้งจอใหญ่และมือถือ
