### 1.1 สาระสำคัญ (จากแผน)
- วงจรอนุกรม คือ การนำโหลดมาต่อเรียงกัน โดยให้ปลายของโหลดตัวแรกต่อกับปลายของโหลดตัวถัดไป หรือ หมายถึง การนำโหลดตั้งแต่สองตัวมาต่อเรียงกันไปแบบอันดับ ทำให้กระแสไหลทิศทางเดียวกัน
- วงจรขนาน หมายถึง การนำโหลดมาต่อขนานกันหรือต่อคร่อมกันตั้งแต่สองตัวขึ้นไป โดยนำจุดต่อของปลายทั้งสองข้างของโหลดแต่ละตัวมาต่อกันร่วมกัน

### 1.2 สมรรถนะประจำหน่วย (Unit competency)
อธิบายองค์ประกอบของวงจรไฟฟ้า วิธีตรวจสอบวงจรไฟฟ้า ประกอบวงจรไฟฟ้าแบบต่าง ๆ เพื่อวัดและคำนวณค่าความต้านทาง[sic → ความต้านทาน]ไฟฟ้า แรงดันไฟฟ้า และกระแสไฟฟ้า

### 1.3 จุดประสงค์การเรียนรู้ (Learning objectives)
1. ด้านความรู้
   1. บอกองค์ประกอบของวงจรไฟฟ้าได้
   2. อธิบายวิธีการตรวจสอบวงจรไฟฟ้าเบื้องต้นได้
2. ด้านทักษะ
   1. คำนวณหาค่าความต้านทานภายในวงจรอนุกรม ขนาน และผสมได้
   2. ประกอบวงจรอนุกรม ขนาน ผสม เพื่อวัดค่าความต้านทานไฟฟ้า แรงดันไฟฟ้า และกระแสไฟฟ้าได้
3. คุณลักษณะที่พึงประสงค์
   1. นำวิธีการตรวจสอบวงจรไฟฟ้า ประกอบวงจรไฟฟ้า ไปประยุกต์การใช้งานได้

### 1.4 ส่วนอื่นของแผน (สรุปย่อ — เป็น boilerplate)
- กิจกรรม: นำเข้าสู่บทเรียน (แจ้งสมรรถนะ/จุดประสงค์) → การเรียนรู้ (เปิดหนังสือเรียน, เปิดงานนำเสนอ, ตอบข้อสงสัย) → สรุป (ทบทวน; ผู้เรียนทำ **ใบงานที่ 3** และ **แบบฝึกหัดบทเรียนที่ 3**)
- การวัดผล: ก่อนเรียน (ตรงต่อเวลา, เตรียมหนังสือ), ขณะเรียน (ตั้งใจฟัง, ร่วมกิจกรรม), หลังเรียน (ใบงานที่ 3, แบบฝึกหัดบทเรียนที่ 3)

**การคำนวณค่าความต้านทาน**

[กล่องสูตร]
```
RT = R1 // R2 // R3 // R4 // ......... // Rn

①  RT = (R1 x R2) / (R1 + R2)

②  RT = 1 / ( 1/R1 + 1/R2 + 1/R3 + 1/R4 + ... 1/Rn )

RT = ค่าความต้านทานรวม
Rn = ค่าความต้านทานตัวสุดท้าย
// = เครื่องหมายแสดงการต่อแบบขนาน
```

> **เด็กควรรู้** เมื่อนำตัวต้านทานที่ค่าเท่ากันขนานกันจะมีค่าเท่ากับค่าของตัวต้านทาน หารจำนวนตัวต้านทานที่ขนาน [ภาพประกอบ: ตัวต้านทาน 2 ตัวขนาน, ขั้ว R_T]

[รูปวงจร: R1 = 10 Ω, R2 = 20 Ω, R3 = 20 Ω ต่อขนาน, ขั้ว R_T]
```
RT = R1 // R2 // R3
RT = 1 / (1/R1 + 1/R2 + 1/R3)
RT = 1 / (1/10 + 1/20 + 1/20)
RT = 1 / (0.1 + 0.05 + 0.05)
RT = 1 / 0.2        RT = 5 Ω
```
ค่าความต้านทานรวมของวงจร RT = 5 Ω

**การคำนวณค่าความต้านทาน**

การคำนวณค่าความต้านทานจะใช้วิธีพิจารณาวงจรในกรณีที่ต่อแบบอนุกรมจะนำค่าความต้านทานมาบวกกัน ในกรณีที่วงจรต่อแบบขนานจะใช้สูตรขนานในการคิดคำนวณ จากรูปสามารถที่จะคำนวณค่าความต้านทานได้ ดังนี้

**ตัวอย่าง** จงคำนวณหาค่าความต้านทานรวมของวงจร
[รูปวงจรผสม; ป้ายในรูป: R1 = 5Ω, R2 = 5Ω (บนขวา), R2 = 20Ω (กลาง), R3 = 5Ω (ขวา), R4 = 5Ω (ล่างซ้าย), R4 = 10Ω (ล่างขวา)]
```
RT1 = R2 + R3 + R4
RT1 = 5 + 5 + 10
```
ค่าความต้านทานของวงจร RT1 = 20 Ω

เขียนวงจรใหม่ได้ ดังนี้
[รูป: R1 = 5 Ω, R5 = 20 Ω ขนานกับ RT1 = 20 Ω, R6 = 5 Ω]
```
RT1 = RT1 // R5
RT1 = (RT1 × R5) / (RT1 + R5)
RT1 = (20 × 20) / (20 + 20)
RT1 = 400 / 40
```
ค่าความต้านทานของวงจร RT2 = 10 Ω

[รูป: R1 = 5 Ω, RT2 = 10 Ω, R6 = 5 Ω ต่ออนุกรม]
```
RT1 = R1 + RT2 + R6
RT = 5 + 10 + 5
```
ค่าความต้านทานของวงจร RT = 20 Ω

**รูปที่ 3.10 (หน้า 50)** — วงจรอนุกรมสี่เหลี่ยม: แบตเตอรี่ด้านซ้าย ป้าย "E = 10 V" (ขั้วบวกด้านบน โดยนัยจากขั้วมิเตอร์), R1 = 1KΩ ด้านบน (แถบ น้ำตาล-ดำ-แดง-ทอง), R2 = 1KΩ ด้านขวาแนวตั้ง, R3 = 500 Ω ด้านล่าง (แถบ เขียว-ดำ-น้ำตาล-ทอง อ่านจากขวา). มิเตอร์เข็มสีเหลือง 3 ตัว แต่ละตัวต่อ **ขนาน (คร่อม)** กับตัวต้านทาน 1 ตัวด้วยลูกศรชี้ขาสองข้าง: R1 ⊕ ซ้าย ⊖ ขวา; R2 ⊕ บน ⊖ ล่าง; R3 ⊖ ซ้าย ⊕ ขวา (ขั้วถูกต้องตามทิศกระแสตามแบบนิยม: ออกจาก + ด้านบนของแบตเตอรี่ → R1 → R2 → R3 → กลับ −)

**รูปที่ 3.11 (หน้า 50)** — วงจรเดียวกับ 3.10 (E = 10 V, R1 = 1KΩ, R2 = 1KΩ, R3 = 500 Ω); มิเตอร์เข็ม 1 ตัวต่อ **อนุกรม** ระหว่างขั้วบนของแบตเตอรี่กับ R1: ⊕ ด้านแบตเตอรี่, ⊖ ด้าน R1 (ถูกต้อง)

**รูปที่ 3.12 (หน้า 50)** — ขั้ว R_T 2 วงด้านซ้าย; บัสบนและล่างแนวนอน; ตัวต้านทานแนวตั้ง 4 ตัว R1, R2, R3, Rn (แถบ แดง-ดำ-น้ำเงิน-เหลือง), จุดต่อ (dot) ดำที่บัส, ช่วงระหว่าง R3 กับ Rn บัสเป็นเส้นประ "……" แสดงว่ามีได้หลายตัว

**ภาพเด็กควรรู้ (หน้า 51)** — ภาพเอียง: ตัวต้านทาน 2 ตัว (แถบ เหลือง-ดำ-แดง ฯลฯ) ขนานในกรอบสี่เหลี่ยม มีจุดต่อ 2 จุด ขั้ว R_T ซ้าย

**วงจรตัวอย่างขนาน (หน้า 51)** — ขั้ว R_T ซ้าย; บัสบน/ล่าง; ตัวต้านทานแนวตั้ง 3 ตัวพร้อมจุดต่อ: R1 = 10 Ω (แถบจากล่าง น้ำตาล-ดำ-ดำ, ทองด้านบน), R2 = 20 Ω (แดง-ดำ-ดำ, ทอง), R3 = 20 Ω (แดง-ดำ-ดำ, ทอง)

**รูปที่ 3.13 (หน้า 52)** — แบตเตอรี่ซ้าย ป้าย E, ⊕ บน ⊖ ล่าง; ตัวต้านทานแนวตั้ง 3 ตัวขนานกัน (ไม่มีป้ายชื่อ/ค่า; แถบ แดง-ดำ-น้ำเงิน-เหลือง), จุดต่อบัส; มิเตอร์เข็ม 3 ตัว แต่ละตัวอยู่ขวาของตัวต้านทาน มีลูกศร + ไปขาบน และ − ไปขาล่าง (ต่อขนาน; ขั้วถูกต้อง)

**รูปที่ 3.14 (หน้า 52)** — แบตเตอรี่ E ซ้าย (⊕ บน, ⊖ ล่าง); 3 กิ่งขนาน R1, R2, R3 แต่ละกิ่งมีมิเตอร์เข็มต่อ **อนุกรม** ระหว่างบัสบนกับหัวตัวต้านทาน: ⊕ ด้านบัสบน, ⊖ ด้านตัวต้านทาน; ลูกศรชี้ลง IR1, IR2, IR3 ข้างแต่ละกิ่ง (ถูกต้อง). ไม่มีการวัดกระแสรวม IT

**รูปที่ 3.15 (หน้า 52)** — ขั้ว R_T ซ้าย. เส้นบน: R1 = 5 Ω → node A → R2 = 5 Ω → มุมขวาบน → R3 = 5 Ω (แนวตั้งขวา) → มุมขวาล่าง → R4 = 10 Ω → node B → R6 = 5 Ω → ขั้ว R_T ล่าง. R5 = 20 Ω ต่อแนวตั้งระหว่าง node A และ node B (มีจุดต่อ). แถบสี: R1/R2/R3/R6 = เขียว-ดำ-ดำ-ทอง (**= 50 Ω ไม่ใช่ 5 Ω** — ดูข้อ 4), R5 = แดง-ดำ-ดำ-ทอง (20 Ω), R4 = น้ำตาล-ดำ-ดำ-ทอง (10 Ω)

**วงจรผสมหน้า 53 (3 ขั้น)**
- ขั้น 1: วงจรเดียวกับ 3.15 แต่ป้ายต่างกัน: R1 = 5Ω, R2 = 5Ω (บนขวา), "R2 = 20Ω" (กลาง — ควรเป็น R5), R3 = 5Ω, "R4 = 5Ω" (ล่างซ้าย — ควรเป็น R6), R4 = 10Ω
- ขั้น 2: R1 = 5 Ω บน, R5 = 20 Ω แนวตั้งกลาง, RT1 = 20 Ω แนวตั้งขวา (ขนานกับ R5), R6 = 5 Ω ล่าง, ขั้ว R_T ซ้าย
- ขั้น 3: R1 = 5 Ω บน, RT2 = 10 Ω แนวตั้งขวา, R6 = 5 Ω ล่าง, ขั้ว R_T ซ้าย (อนุกรม)

## 5. Gaps & suggested additions (ภายในขอบเขตบทเรียน)

1. **ใบงานที่ 3 / แบบฝึกหัดบทเรียนที่ 3 / แผนการฝึกปฏิบัติ** ไม่มีในภาพ — ต้องจัดทำ (ข้อเสนอในส่วน 6 และตัวอย่างข้อสอบด้านล่าง)
2. **กฎของโอห์ม (Ohm's law)** V = I × R — บทนี้ให้ "วัดและคำนวณ…แรงดัน และกระแส" ตามสมรรถนะ แต่ไม่มีสูตรคำนวณ V และ I เลย มีแต่ R_T. ควรเพิ่มอย่างน้อย I_T = E / R_T และ V_n = I × R_n เพื่อให้ผู้เรียนเทียบค่าวัดกับค่าคำนวณ (แผนบูรณาการคณิตศาสตร์ก็อ้างถึง)
3. **คุณสมบัติวงจร 3 แบบ (ตารางสรุป)**:
   | | อนุกรม | ขนาน |
   |---|---|---|
   | กระแส | I_T = I1 = I2 = I3 | I_T = I1 + I2 + I3 (KCL) |
   | แรงดัน | E = V1 + V2 + V3 (KVL) | E = V1 = V2 = V3 |
   | ความต้านทาน | R_T = ΣR (มากกว่าตัวมากสุด) | 1/R_T = Σ1/R (น้อยกว่าตัวน้อยสุด) |
   | ถ้าโหลดตัวหนึ่งขาด | ทั้งวงจรดับ | ตัวอื่นยังทำงาน |
4. **ตัวอย่างเชิงตัวเลขของรูป 3.10/3.11** (E = 10 V, 1 k + 1 k + 500 Ω): R_T = 2.5 kΩ, I = 4 mA, V1 = V2 = 4 V, V3 = 2 V, ΣV = 10 V — ใช้เป็นตัวอย่างและเฉลยใบงาน
5. **ตัวอย่างขนานพร้อมกระแสกิ่ง** (สเกลให้ปลอดภัย): E = 10 V, R1 = 1 kΩ, R2 = R3 = 2 kΩ → R_T = 500 Ω, I1 = 10 mA, I2 = I3 = 5 mA, I_T = 20 mA (KCL ✔)
6. **ตัวอย่างวงจรผสมพร้อมแรงดัน/กระแส** (ต่อจากหน้า 53 ด้วย E = 10 V): R_T = 20 Ω → I_T = 0.5 A; V_R1 = V_R6 = 2.5 V; V_AB = 0.5 × 10 = 5 V; I_R5 = 5/20 = 0.25 A; I_(R2,R3,R4) = 0.25 A → V_R2 = V_R3 = 1.25 V, V_R4 = 2.5 V; ตรวจ KVL: 2.5 + 5 + 2.5 = 10 V ✔; KCL ที่ node A: 0.5 = 0.25 + 0.25 ✔. (หมายเหตุ: ค่า Ω ต่ำแบบนี้ใช้ได้เฉพาะคำนวณ — สำหรับแล็บให้ ×100 ดูส่วน 6)
7. **กำลังไฟฟ้า (power) เบื้องต้น** P = V × I = I²R = V²/R — เพื่อเลือกพิกัดวัตต์ของตัวต้านทาน (¼ W) ให้ปลอดภัยตอนทดลอง; ไม่ต้องลงลึก
8. **วิธีตรวจสอบวงจรไฟฟ้าเบื้องต้น** (จุดประสงค์ข้อ 1.2) — หนังสือไม่มีหัวข้อนี้เลย: ควรเพิ่ม การตรวจความต่อเนื่อง (continuity test, beep), การหาจุดขาด (open circuit) ด้วยการวัดแรงดันตามจุด, การตรวจลัดวงจร (short) ด้วยโอห์มมิเตอร์, การตรวจฟิวส์ขาด
9. **การใช้มัลติมิเตอร์ (ส่วนประกอบ/ช่องเสียบ/การอ่านสเกล)** — ช่อง COM, VΩ, mA, 10A; การเลือกย่าน; ผลของการต่อผิด (แอมมิเตอร์คร่อมแหล่งจ่าย = ลัดวงจร)
10. **สัญลักษณ์มาตรฐาน IEC 60617 vs ANSI** สำหรับ R, แหล่งจ่าย, สวิตช์, ฟิวส์, หลอด, Ⓐ, Ⓥ, Ω
11. **การอ่านรหัสสีตัวต้านทาน** อย่างย่อ (เชื่อมกับรูปที่แถบสีผิด — Error #3) และอนุกรม E12

### 6.6 ความปลอดภัย
- ใช้เฉพาะแรงดัน DC ต่ำ (≤ 12 V) จากแหล่งจ่ายจำกัดกระแส ตั้ง current limit ≈ 50 mA
- **ปลดแหล่งจ่ายก่อนวัดโอห์มและก่อนต่อ/ถอดแอมมิเตอร์ทุกครั้ง**; ตรวจช่องเสียบสายวัด (mA vs VΩ) ก่อนจ่ายไฟ; ตั้งย่านสูงสุดก่อนเสมอ
- ห้ามต่อแอมมิเตอร์คร่อมแหล่งจ่ายหรือคร่อมโหลด
- ตรวจพิกัดวัตต์: P = V²/R ต้อง < ½ ของพิกัด (¼ W) — ตัวต้านทานร้อนจัดสัมผัสอาจไหม้มือ
- การสาธิตอุปกรณ์ไฟบ้าน 220 V AC (เช่น ฟิวส์ในแผงไฟ, เครื่องใช้ไฟฟ้ารูป 3.4), การใช้หัวแร้งบัดกรี และงานที่เกิดความร้อน — **ให้ครูเป็นผู้สาธิต/ควบคุมดูแลเท่านั้น** ผู้เรียนไม่ปฏิบัติกับไฟบ้านเอง
- สวมแว่นตานิรภัย, โต๊ะแห้ง, ไม่สวมเครื่องประดับโลหะ, รายงานครูทันทีเมื่อมีกลิ่นไหม้หรือฟิวส์ขาด

### 6.7 เกณฑ์ประเมิน (เสนอ)
ต่อวงจรถูกตามแบบ (20%) · ต่อมิเตอร์ถูกชนิด/ขั้ว/ย่าน (25%) · ค่าวัดสอดคล้องค่าคำนวณ ±10% (20%) · ตรวจ KVL/KCL และสรุปผล (20%) · ความปลอดภัยและการเก็บเครื่องมือ (15%)
