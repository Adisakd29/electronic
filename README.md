# แพลตฟอร์มการเรียนรู้ งานไฟฟ้าและอิเล็กทรอนิกส์เบื้องต้น (20100-1005)

เว็บไซต์จัดการเรียนการสอนออนไลน์สำหรับนักเรียน ปวช. รายวิชา **งานไฟฟ้าและอิเล็กทรอนิกส์เบื้องต้น รหัส 20100-1005** (ทฤษฎี 1 ปฏิบัติ 3 หน่วยกิต 2) ครบ 18 สัปดาห์ สัปดาห์ละ 4 ชั่วโมง พัฒนาจากแผนการจัดการเรียนรู้มุ่งเน้นสมรรถนะ 15 หน่วยการเรียนรู้ โดยตรวจทาน แก้ไข และเขียนเนื้อหาใหม่ทั้งหมด

## สิ่งที่มีในระบบ

| ส่วน | รายละเอียด |
|---|---|
| บทเรียน 18 สัปดาห์ | 180 ขั้นเรียนรู้ (Step), 484 กิจกรรมเชิงโต้ตอบ, 145 ตัวอย่างพร้อมเฉลยทีละขั้น, 287 ภาพประกอบ SVG ที่วาดใหม่, ภาพถ่ายอุปกรณ์จริง 40 ภาพ (Wikimedia Commons สัญญาอนุญาตแบบเปิด เครดิตที่ `/credits`), 80 ใบงานปฏิบัติพิมพ์ได้, คลังข้อสอบ 551 ข้อ |
| เรียนได้โดยไม่ต้องมีบัญชี | โหมดผู้เยี่ยมชม: เปิดบทเรียน กิจกรรม และห้องทดลองได้ทุกสัปดาห์ ความก้าวหน้าเก็บในเบราว์เซอร์เครื่องนั้น ไม่มีแบบทดสอบ คะแนน และการส่งใบงาน (ปิดได้ด้วย `GUEST_MODE=off`) |
| นักเรียนต่างแผนก | กรอบ "เข้าใจแบบง่าย ๆ ก่อน" ต้นขั้นเรียนรู้, กรอบ "ลงลึก" พับเก็บส่วนที่ไม่ออกสอบ, ตัวอย่าง "ในงานแผนกของคุณ" 6 แผนก (นักเรียนเลือกเอง หรือครูตั้งให้ทั้งห้อง) — สมรรถนะและการประเมินเหมือนกันทุกแผนก |
| เส้นทางการเรียน | บทนำ → เรียนรู้ → ฝึกปฏิบัติเชิงโต้ตอบ → ห้องทดลองเสมือน → แบบทดสอบ → สรุปและจบบท บันทึกความก้าวหน้าอัตโนมัติ กลับมาเรียนต่อจากตำแหน่งล่าสุดได้ |
| ห้องทดลองเสมือน 10 ชุด | วงจรไฟฟ้ากระแสตรง, กฎของโอห์ม, แถบสีตัวต้านทาน, ประจุ–คายประจุตัวเก็บประจุ, ตัวเหนี่ยวนำและหม้อแปลง, รีเลย์, สารกึ่งตัวนำ, การควบคุมมอเตอร์ DC, มัลติมิเตอร์, ออสซิลโลสโคป รวม 178 ภารกิจที่ตรวจผลอัตโนมัติ ทุกชุดระบุข้อสมมติและขอบเขตความแม่นยำ |
| การประเมินผล | แบบทดสอบก่อนเรียน 5 ข้อ และหลังเรียนที่สุ่มจากคลังข้อสอบ (ไม่ซ้ำชุดเดิม) ตรวจคำตอบที่เซิร์ฟเวอร์ ส่งใบงาน ครูตรวจด้วยรูบริก ประเมินสมรรถนะปลายภาค |
| นักเรียน | แดชบอร์ดความก้าวหน้า คะแนน ใบงาน ประวัติการเรียน XP/Level/Achievement ใบประกาศนียบัตรพร้อมรหัสตรวจสอบ |
| ครู | ภาพรวมห้อง ความก้าวหน้ารายบุคคล คะแนนก่อน–หลังเรียน คำถามที่ตอบผิดบ่อย ผล Virtual Lab ใบงานที่ส่ง/ยังไม่ส่ง ประเมินสมรรถนะ ตั้งเกณฑ์ปลดล็อก แก้ไขคลังข้อสอบ ส่งออก CSV/Excel |
| ผู้ดูแลระบบ | จัดการผู้ใช้ ห้องเรียน/ภาคเรียน รายชื่อ Google ที่อนุญาต สำรองข้อมูล บันทึกการใช้งาน |

## เทคโนโลยี

Next.js 16.4 (App Router, Cache Components) · React 19 · TypeScript · Tailwind CSS 4 · PostgreSQL + Drizzle ORM · better-auth (ชื่อผู้ใช้/รหัสผ่าน และ Google) · Vitest · Playwright

เนื้อหาบทเรียนเก็บเป็นข้อมูลแบบมีโครงสร้าง (TypeScript, ตรวจด้วย type และ validator) แยกจากส่วนติดต่อผู้ใช้ที่ `src/content/` ส่วนข้อมูลผู้เรียนและคลังข้อสอบที่ครูแก้ไขเก็บใน PostgreSQL

## เริ่มใช้งานบนเครื่องพัฒนา

ต้องมี Node.js ≥ 22 และ PostgreSQL ≥ 14

```bash
npm install
# สร้างฐานข้อมูล
createuser -P eelearn            # รหัสผ่าน: eelearn
createdb -O eelearn eelearn
createdb -O eelearn eelearn_test # สำหรับ smoke test
# ตั้งค่า
cat > .env.local <<'ENV'
DATABASE_URL=postgres://eelearn:eelearn@localhost:5432/eelearn
BETTER_AUTH_SECRET=dev-secret-change-me-0123456789abcdef0123456789
BETTER_AUTH_URL=http://localhost:3000
UPLOAD_DIR=./.uploads
ENV
npm run db:migrate
npm run db:seed      # คลังข้อสอบ + บัญชีทดลอง (เฉพาะ development)
npm run dev          # http://localhost:3000
```

บัญชีทดลอง (สร้างเฉพาะ development หรือเมื่อตั้ง `SEED_DEMO=1` — **ห้ามใช้บนเว็บจริง**)

| บทบาท | ชื่อผู้ใช้ | รหัสผ่าน |
|---|---|---|
| ผู้ดูแลระบบ | `admin` | `Admin1234!` |
| ครู (ห้อง ชฟ.1/1 ภาคเรียน 2/2569) | `teacher` | `Teacher1234!` |
| นักเรียน | `student01` – `student03` | `Student1234!` |

## คำสั่งที่ใช้บ่อย

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` / `npm run build` / `npm start` | พัฒนา / build production / รัน production |
| `npm run typecheck` · `npm run lint` | ตรวจ type และ lint |
| `npm test` | unit test (ฟิสิกส์ของห้องทดลอง, ตรวจคำตอบ, ปลดล็อก, ข้อสอบ, XP, สิทธิ์) |
| `npm run content:check -- --all` | ตรวจโครงสร้างเนื้อหาทั้ง 18 สัปดาห์ (id ซ้ำ, การอ้างอิง, ภาพ, preset/check ของแล็บ) |
| `npx tsx --conditions=react-server scripts/smoke-db.ts` | ทดสอบเส้นทางหลักของเซิร์ฟเวอร์กับฐานข้อมูล `eelearn_test` (ล้างข้อมูลในฐานทดสอบ) |
| `npm run test:e2e` | ทดสอบผ่านเบราว์เซอร์จริง (ต้องรันเซิร์ฟเวอร์ไว้ที่ `BASE`, ค่าเริ่มต้น http://localhost:3000) |
| `npm run db:migrate` · `npm run db:seed` · `npm run db:release` | migration / seed / ทั้งสองอย่าง (ใช้ตอน deploy) |
| `npm run db:backup` | สำรองฐานข้อมูลด้วย `pg_dump` ไปที่ `./backups` |
| `npm run fig:render` · `npm run lab:render` | เรนเดอร์ภาพประกอบ/ห้องทดลองเป็น PNG เพื่อตรวจด้วยตา |

## ความปลอดภัยและข้อมูลส่วนบุคคล

- นักเรียนเข้าถึงได้เฉพาะข้อมูลของตนเอง ครูเห็นเฉพาะห้องที่สอน ทุก Server Action ตรวจ session และสิทธิ์ใหม่ทุกครั้ง (ทดสอบใน smoke-db และ e2e)
- เก็บข้อมูลส่วนบุคคลเท่าที่จำเป็น: ชื่อ ชื่อผู้ใช้ เลขประจำตัว (ถ้ามี) อีเมล Google (เฉพาะผู้ใช้ Google) ไม่มีการเก็บข้อมูลอื่น
- ไฟล์ใบงานตรวจชนิดไฟล์จาก magic bytes จำกัด 10 MB ดาวน์โหลดได้เฉพาะเจ้าของ ครูของห้อง และผู้ดูแลระบบ
- ห้องทดลองทุกชุดเป็นแรงดันต่ำ งานที่เกี่ยวกับไฟบ้าน 230 V มีป้าย “ครูสาธิตเท่านั้น” และใบงานระดับ S2/S3 ระบุให้ทำภายใต้การควบคุมของครู
